The Six-Part Ask — and the Prompt Scorer

First the check, then the tool you’ll use forever: write a real prompt for your actual job and score it against the anatomy.

The anatomy, one line each

  • ROLE — “Act as an operations manager…” sets the lens.
  • CONTEXT — what it can’t know: your company, situation, audience.
  • TASK — one clear verb: draft, summarize, compare, list, rewrite.
  • FORMAT — the container: bullets, table, three paragraphs, 100 words.
  • CONSTRAINTS — tone, length, what to avoid, what must stay.
  • ITERATE — round two is where it gets good: shorter · warmer · as a table.

Anything unclear in my notes, list separately as “to confirm” rather than guessing. Tap to flip back

Scenario 3 — The inventory question

You export a spreadsheet of on-hand stock and last month’s sales. The boss asks: “What are we going to run out of first?”

Module 5 · Reference

Glossary — the words, in plain English

Every term you’ll hear in this program and in Dash, defined the DashRite way. Skim it once; come back when a word snags you.

The essentials

  • Claude — the AI assistant we use. A brilliant drafter that works from what you give it; it is never a system of record and never the accountable party.
  • Prompt — the instruction you give Claude. The better the prompt, the better the draft. See the Six-Part Ask.
  • The Six-Part Ask — DashRite’s prompt anatomy: Role · Task · Context · Format · Constraints · Example. Hit all six and the guessing disappears.
  • Context — the background you hand Claude (the numbers, the situation, the history). “Context in, quality out.” It only knows what you provide.
  • Iteration — the round-two-and-three of refining a draft (“tighter and warmer, under 120 words”). The workflow, not a failure.
  • Hallucination — when Claude states something false with full confidence. Why the trust habit exists: confidence is not accuracy.
  • The trust habit — the one rule of the program: Claude drafts → you verify → you own it. Accountability never transfers to a tool.

Working with it

  • Chat — one conversation. By default a new chat knows nothing about your last one.
  • Project — a workspace with standing instructions + knowledge files every chat inside can use. How recurring work gets consistent context.
  • Knowledge files — the documents you load into a Project so Claude works from your real material every time.
  • Instructions — the standing “how we do it here” rules saved in a Project so you don’t retype them.
  • Verification — checking a draft against a source you trust before it travels. “Sounds right” earns a check, not a pass.
  • Guardrails — what never goes in: client data, financials, anything confidential. The data-handling rule you sign.
  • Capstone — the real project you finish the program with — proof of competence, and the natural door to a retainer.

The DashRite frame

  • Built RITE! — the standard behind every deliverable. Respect · Integrity · Teamwork · Excellence.
  • Measure before you manage — the operating creed: you can’t manage what you haven’t measured, and a number that stopped telling the truth is the most expensive thing in a business.
  • The five parts — what every DashRite project ships with: a working deliverable, a documented workflow, a how-to guide, an executive overview, and it’s built in tools you already own.
  • Yours when we leave — the promise: the system is built in your own tools and belongs to you outright when the engagement ends.
  • Free Business Health Assessment — how every engagement opens: real findings, in writing, then you decide.
